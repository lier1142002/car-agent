AutoSalesAgent 前后端架构方案选择

后端 API + 前端 UI，哪个技术组合适合本项目？

A

React 18 + TypeScript + FastAPI

现代化 SPA 架构，组件化开发，生态丰富。FastAPI 提供 REST API + WebSocket。使用 Vite 构建，Ant Design 组件库。

优势

  • 组件化，可维护性强
  • TypeScript 类型安全
  • Ant Design 企业级 UI 组件
  • Vite 极速构建

代价

  • 需要 Node.js 环境
  • 构建步骤复杂
  • 学习曲线较陡
B

Vue 3 + TypeScript + FastAPI

轻量级 SPA，Composition API，上手简单。FastAPI 提供 REST API。Vite 构建，Element Plus 组件库。

优势

  • 更轻量，学习曲线平缓
  • Composition API 灵活
  • Element Plus 成熟稳定

代价

  • 生态较 React 小
  • 企业级项目案例较少
C

FastAPI + Jinja2 模板 (零构建)

服务端渲染 HTML，无前端构建步骤。FastAPI 直接返回页面，配合 HTMX 实现局部刷新。

优势

  • 零构建，部署极简
  • 纯 Python 技术栈
  • 启动快，无 Node 依赖

代价

  • 交互体验受限
  • 不支持复杂 UI 状态
  • 前端生态缺失
